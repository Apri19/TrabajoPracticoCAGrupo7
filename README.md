Este repositorio contiene los respaldos comprimidos de los directorios solicitados:

* root.tar.gz: Directorio personal de root.

* etc.tar.gz: Configuraciones del sistema y servicios.

* opt.tar.gz: Scripts de mantenimiento (backup\_full.sh) y binarios opcionales.

* proc.tar.gz: Contenido evaluable de /proc (incluye archivo particion).

* www\_dir.tar.gz: Archivos del servidor web Apache (index.php, recursos).

* backup\_dir.tar.gz: Respaldo almacenado en la partición /dev/sdc2.

* var.tar.gz.part\_0\*: Directorio /var fragmentado en bloques de 25 MB.

* var.tar.gz: Directorio /var completo, como queríamos aprender a descomprimir los  archivos fragmentados, los unimos para saber si se podían descomprimir correctamente, y lo dejamos en la entrega.

La configuración de empaquetado del apt que vimos en clase(las que incluían archive.debian.org) no nos funcionó correctamente, por lo que utilizamos otras url para definir el destino de búsqueda del apt.
